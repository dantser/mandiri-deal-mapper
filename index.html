MANDIRI Deal Mapper

Берёт CSV-выгрузку сделок из Bitrix24 (воронка «Контракт», стадия «Набитие платежа в БК»), переименовывает поля по маппингу MANDIRI, добавляет служебные константы и собирает итоговый файл ровно в 73 позиции формата Separated — готовый к загрузке в форму «Multiple Transfer by File Upload». Всё считается в браузере — файл никуда не отправляется.

Исключено — крупные сделки

Сумма ≈ выше 100 000 USD (по приблизительному курсу) — источника для Underlying Document Code в Bitrix нет, поэтому эти сделки не попадают в результат и не входят в скачиваемый CSV. Обработайте их отдельно вручную, пока не появится источник кода документа.

Underlying Document Code

Источника в Bitrix нет. Пока что сделки с суммой выше 100 000 USD (или эквивалент по курсу ниже) просто исключаются из результата и показываются отдельным списком «на ручную обработку».

Курсы зафиксированы на (xe.com, mid-market) — только для отсечки порога, не для платежа. Со временем устареют, обновляйте вручную.
